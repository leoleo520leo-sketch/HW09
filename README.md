## 一、程式用途與執行方式

### 程式用途
本程式以 Python 基本資料型別（`str`、`list`、`tuple`、`dict`、`set`）與字串格式化（`f-string`）製作「兩場活動報名整理器」。程式會清理「桌遊體驗」與「電影欣賞」兩場活動的原始報名文字（移除多餘半形空白、統一轉為小寫），透過集合運算進行去重與交集、聯集、差集名單比對，最後自動計算各場人數、總不重複人數、報名人次及應收費用，輸出完整報表摘要。

## 三、個人回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
Amy 與 amy整理後是同一人 同場活動只收一次費所以算 3 人 list 保留順序與重複紀錄但沒有唯一性 set 保留唯一性與集合比對能力但沒有固定順序。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
兩場去重後都是 amy, ben, cora 共 3 人且完全重疊（交集、聯集皆為 3 人，差集皆為空集合） 但報名人次是兩場相加 $3 + 3 = 6$ 人次 總應收則是 $3 \times 120 + 3 \times 80 = 600$ 元。
